# Software Factory: UX Arc Overview

Date: 2026-07-22
Status: Living document, specced incrementally

Records the sequence agreed after a UX and game-design sweep. Each
increment gets its own detailed spec when it is reached; this file holds
the ordering and the reasoning so the arc survives between sessions.

## The diagnosis

Measured on the shipped build (1440x1000 viewport, desktop):

| Metric | Fresh | Mid-game |
| --- | --- | --- |
| Page height | 2322px | 2386px |
| Screens of scroll | 2.3 | 2.4 |
| "Alter the loop" panel | 1312px (56% of page) | 1166px |
| Both loop diagrams | 618px | 618px |
| Sidebar content vs main column | 124px vs 1749px | 434px vs longer |
| Buttons on screen | 24 | 25 |

The proportions are inverted for how an idle game is played: roughly 95
percent watching, 5 percent spending, yet the shop occupies more than
half the page and the machine sits above it, so the player scrolls away
from the loops to spend and back again to watch. Paperclips avoids this
by fitting in one screen; this game kept the visual language but has
outgrown the density.

Three consequences: nothing is ever collapsed (no progressive
disclosure, so the UI can only grow with content); everything carries
the same visual weight (no entry point, and the two diagrams read as
near-duplicates); and change is invisible (silent ticks, a flat event
log where an urgent choice looks like routine scope creep).

## The increments

P0.1 product plan (user stories, FRs/NFRs, per-ticket DoD):
`docs/superpowers/specs/2026-08-07-p01-cockpit-watchability-plan.md`.

1. Speed controls. Reaching day 600 currently costs ten real minutes of
   waiting, which caps how fun the game can be regardless of its
   systems. Smallest change, largest playability gain. Specced in
   2026-07-22-speed-controls-design.md. **Shipped.**
2. Cockpit layout. Sticky stats, both loops pinned in view, and the
   shop / projects / owned panels behind tabs so only one is open at a
   time. Targets the 2.4 screens of scroll and the inverted proportions.
   **P0.1 NEW-C.**
3. Goals and event prominence. A next-goal indicator (next milestone,
   next contract tier) so the endless loop has something to reach for,
   and pending choices surfaced as a banner rather than a log line.
   Sequenced close behind increment 2 because tabs risk hiding a
   completed contract, and this is what compensates.
   **P0.1 NEW-B + #40 (+ NEW-A bottleneck cue).**
4. Game feel. Changed numbers flash briefly so a tick is noticeable, and
   the hiring gamble gets a reveal moment instead of a log line.
   **P0.1 NEW-D.**

## What to keep

The monospace restraint, the absence of decoration, the loop diagrams
(the game's signature and the clearest expression of its systems
thesis), the tech tree, and the no-reflow layout stability won in
Release 14.

## Where to diverge from Paperclips

Density discipline (tabs and collapsing are what the aesthetic needs at
this scale), hierarchy (size and dimming, no color required), and
feedback (at one day per second across nine stats, change is invisible
without it).
