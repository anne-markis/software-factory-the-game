# Mock: firing a human drops morale by 40

Open [`index.html`](index.html) in a browser. Static proposal only — not
wired to the engine.

Player Remove on a `human: true` card spends **40 morale**, pending or
already on staff. The confirm names that cost. Agents, payroll failure,
and quits do not.

1. **Remove asks first.** Day 18. A Disaster hire is still joining.
   Morale is still 70. The confirm says it will drop by 40.
2. **The drop lands.** They leave Owned. Morale is 30. The quit arrow
   on the remaining developer is no longer zero. Events records the hit.
3. **An agent is not a person.** The coding-agent confirm stays the old
   line. Morale stays 30.
