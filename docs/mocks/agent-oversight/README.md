# Mock: Agent loop — Oversight

Open [`index.html`](index.html) in a browser. Studio-only sketch for the
agent reinforcing loop. Numbers are illustrative.

Oversight is one company-wide stock. Humans fill it (the founder counts).
Each agent leaks it. Harness slows that leak. Orchestration strengthens
the watch arrow. While Oversight is high, agent throughput matches today's
cards. As it falls, a share of that throughput is still finished and
increasingly off what you asked: extra debt first.

Low Oversight is a dashed coupling into human Morale, in place of the
agents-per-human overload leak. Agents do not quit.

The page toggle only changes the sentence under the diagram. The boxes
stay Oversight either way.
